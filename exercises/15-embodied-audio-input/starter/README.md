# Starter: amplitude sun

The starter begins safely in no-device mode. Up/Down changes a scalar amplitude;
F replays the synthetic fixture; L optionally requests the selected default
microphone only after consent; N stops it. Louder values enlarge an outlined
circle, add rays, and lengthen a meter. Source and mapping remain written on
screen.

Own parameters in `src/design/audio_instrument_design.cpp` and replace the sun
in `src/ofApp.cpp`. Keep the tested core and all keyboard routes. See the
[parent brief](../README.md) for commands, privacy rules, caps, explanations,
and manual review.
