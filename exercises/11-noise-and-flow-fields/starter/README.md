# Section 11 starter: coherent current

The starter draws connected teal histories and coral triangular heads with a
forward direction line. Pointer/drag and arrows move one field-coordinate
control. P pauses, R replays the seed, M keeps current heads only, and T freezes
field time. Replace its design values and rendering grammar rather than changing
only color.

Build and launch from the repository root with the section wrapper. Run the
pure model suite first; native compilation does not prove launch, appearance,
accessibility, or originality.
