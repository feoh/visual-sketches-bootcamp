# Starter

The starter renders an anchor-to-target line, a filled circular anchor, an outlined square target, and an outlined traveler, so endpoint roles do not rely on color. Move the pointer or use arrow keys; the adapter synchronizes edge pointer events to the clamped target before applying 12-pixel key steps. Begin with `src/design/constellation_design.cpp`, then make a connector system that is visually and spatially your own. Keep renderer-independent vector mechanics in `../shared`.
