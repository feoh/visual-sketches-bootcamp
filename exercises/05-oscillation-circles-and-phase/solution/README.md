# Explained solution

## What this example tries

This phase weave uses eleven columns, seven rows, diagonal phase steps, connected row
polylines, and alternating filled/outlined axis-vertex diamonds whose maximum extent is
one mark radius. That structure and negative space intentionally diverge from the
starter's orbit circles, crosshairs, and circular travelers. It is one explanation, not
a target image; make a third relationship rather than recoloring either version.
