# Starter

Edit `src/design/phase_field_design.cpp` for your grid, orbit rhythm, size, and
palette, then replace the orbit-circle/capped-crosshair/traveler treatment in
`src/ofApp.cpp` with your own shapes. Keep pause/reset keys and bounded
responsive behavior. Run `tests/run-section-05-tests.sh`; tests compile this
design but never compare pixels.
