# Section 16 starter: structured chance

The starter builds a 3 × 3 shared warped lattice. Cyan and magenta regional
families inherit one diagonal direction, one region stays sparse, and every line
has a faint wide body plus a bright core.

Change design values in `src/design/structured_chance_design.cpp`, then change
line and seam grammar in `src/ofApp.cpp`. Keep `R`, `N`, `G`, and `H`; make the
non-glow view readable before polishing luminous layers. Build through the
section wrapper from the repository root.
