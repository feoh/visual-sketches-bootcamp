# Section 17 starter: clustered pebbles

The starter makes six parent clusters and 720 elongated sphere instances. Parent
records organize position, orientation, typical scale, and material. A warm and
a cool point light reveal volume on black.

Change model settings in `src/design/population_design.cpp`, then change camera,
primitive proportions, materials, and lights in `src/ofApp.cpp`. Keep `R`, `N`,
`P`, `M`, and `H`; use pause and reduced detail while evaluating a dense seed.
Build through the section wrapper from the repository root.
