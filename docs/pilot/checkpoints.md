# Checkpoint prompts

These are optional remix prompts. Try one from memory if that sounds useful, and
open the lesson or API references whenever you need them. Note which explanation
or example helped you get unstuck.

If you like, jot down how the task felt before and after. Plain words such as
“lost,” “finding my way,” or “ready to adapt it” are enough.

## After Unit 0

From a clean shell or IDE state, find `OF_ROOT`, regenerate/open the appropriate
project, run the first-C++ known-case test, explain a deliberately failing
assertion, repair it, and rerun. Existing installed dependencies may be reused;
record reused setup separately from first-time setup.

## After Unit 2

Create a deterministic still or short loop that uses one seeded choice from
section 06 inside at least two local coordinate frames from section 07, and maps
one sampled gesture measurement from section 08 to a visible property. Add one
meaningful invariant test and explain the mapping visually, numerically, and
symbolically.

## Complete path

Use one section 19 idea and its saved replay or frame-time example. Explore one
mechanism more deeply and make the structure your own. Keep whichever optional
plan, test note, capture note, or credits list will genuinely help you return to
the project.

After each prompt, continue, revise, pause, or wander back to another sketch.
